# TFM

TFM 是一个轻量级的终端伪 GUI 文件管理器，基于 Python 标准库实现。它通过 ANSI 控制码和文本光标控制，在终端中展示简单的目录浏览界面。

## 功能

* 目录浏览
* 支持上下左右方向键导航
* `Enter` 进入目录
* `Backspace` 返回上级目录
* `Esc` 退出程序
* 自动适配终端大小
* 支持中英文字符宽度计算，避免中文显示错位

## 运行方式

在项目根目录下运行：

```bash
python main.py
```

可选传入初始路径：

```bash
python main.py C:\Users
python main.py /home/user
```

如果不传路径，则默认从当前工作目录启动。

## 快捷键说明

* `↑`：向上移动当前选中项
* `↓`：向下移动当前选中项
* `←`：上一页
* `→`：下一页
* `Enter`：进入选中目录
* `Backspace`：返回上一级目录
* `Esc`：退出程序

## 目录结构

主要文件：

* `main.py` - 程序入口与界面逻辑
* `key.py` - 跨平台按键读取
* `v.py` - ANSI 颜色和样式定义

## 说明

* 该项目仅依赖 Python 标准库，无需额外安装第三方包。
* 当前版本主要用于目录导航，暂不包含文件操作功能。
* 终端需要支持 ANSI 控制码以获得更好的显示效果。
